# 小程序重构 Checklist（打印版）

> 用法：每次 PR 前对照勾选；或在设计评审时逐项过一遍。
> 整页严重不及格（Level 1 < 80%）时，先重写 wxss 再做后续重构。

## Level 1 — 基础模范

| | 检查项 | 备注 |
|--|--|--|
| ☐ | 所有尺寸用 rpx，不用 px（除非 1rpx 边框） | |
| ☐ | 所有间距是 8 的倍数 | 16/24/32/48/64 |
| ☐ | 字号层级 ≤ 5 级 | |
| ☐ | 颜色用 design tokens，不写死 hex | var(--md-*) |
| ☐ | 圆角统一（按钮/卡片/头像各成体系） | |
| ☐ | 阴影统一（用 --md-shadow-sm/md/lg） | |
| ☐ | 字体粗细 ≤ 3 档（regular/medium/semibold） | |

## Level 2 — 信息架构

| | 检查项 | 备注 |
|--|--|--|
| ☐ | 单一页面单一任务 | |
| ☐ | 跳转深度 ≤ 3 层 | |
| ☐ | 首屏 3 秒内能看懂"这是什么、能做什么" | |
| ☐ | 减少输入，提供预设选项 / 历史 / 推荐 | |
| ☐ | 主 CTA 唯一、醒目、品牌色 | |
| ☐ | 无关元素已删除（"够用就行"原则） | |

## Level 3 — 反馈与交互

| | 检查项 | 备注 |
|--|--|--|
| ☐ | 列表/详情有骨架屏 | |
| ☐ | 所有可点击元素有 hover-class | |
| ☐ | 表单提交按钮在加载时变 disabled + "提交中..." | |
| ☐ | 错误提示就近显示，不用 Toast | |
| ☐ | 成功 Toast 1.5s 自动消失 | |
| ☐ | 必须知晓的结果用 Modal 或结果页 | |
| ☐ | 空状态有插画 + 友好文案 | |
| ☐ | 网络错误页有"重试"按钮 | |

## Level 4 — 细节专业度

| | 检查项 | 备注 |
|--|--|--|
| ☐ | TabBar 选中态用实心图标，未选用线性 | |
| ☐ | 卡片有微阴影（--md-shadow-sm） | |
| ☐ | hero 卡片差异化设计（不和小卡同质） | |
| ☐ | 列表项按下时有视觉反馈 | |
| ☐ | 滚动到底部时优雅停止，不"撞墙" | |
| ☐ | 顶部胶囊按钮区域已适配 | |
| ☐ | iPhone X 底部安全区已留 | |
| ☐ | 图片有 lazyload，列表有虚拟滚动（>50项时） | |

## Level 5 — 品牌一致性

| | 检查项 | 备注 |
|--|--|--|
| ☐ | 主色只有 1 个 | |
| ☐ | 辅助色 ≤ 2 个 | |
| ☐ | 所有页面 import 同一份 design-tokens.wxss | |
| ☐ | 插画/图标风格统一 | |
| ☐ | 文案语气统一（都活泼 OR 都正式） | |
| ☐ | logo / 品牌名 / tagline 出现位置一致 | |

## Level 6 — 合规与隐私（小程序特有）

| | 检查项 | 备注 |
|--|--|--|
| ☐ | 用户授权弹窗有明确说明用途 | |
| ☐ | 不强制要求授权才能使用 | |
| ☐ | 隐私政策入口可达 | |
| ☐ | 不诱导分享 / 不强制关注 | |
| ☐ | 未成年人保护提示（如涉及） | |

---

## 评分

- Level 1 全 ☑ → **及格**
- Level 1-3 全 ☑ → **可上线**
- Level 1-4 全 ☑ → **专业**
- Level 1-5 全 ☑ → **优秀，团队样板**
