## 一、设计原则

### 核心方向
- **情感稳定，不是情感夸张** — 用户处于高情绪状态，界面要像一个冷静的朋友，不煽动也不冷漠
- **克制的关怀** — 每一个文案、每一个颜色、每一个间距都在传达"我在，但我不越界"
- **信任感优先于美感** — 可读性 > 视觉花哨，结构清晰 > 视觉复杂

### 明确避免
- ❌ 粉色、红心、浪漫社交感（不是恋爱 App）
- ❌ 医疗冷白 + 蓝色系（不是心理诊所）
- ❌ 赛博科技感、紫色发光、渐变霓虹
- ❌ 过多动画和视觉噪音（用户情绪不稳定，不需要更多刺激）

## 三、字体系统

### 字体选择

| 用途 | 字体 | 备注 |
|---|---|---|
| 中文主字体 | `PingFang SC` / `Noto Sans SC` | 系统字体优先，保证渲染稳定 |
| 数字/英文 | `DM Sans` | 从 Google Fonts 引入，现代但不冷漠 |
| 代码/数据 | `JetBrains Mono` | 仅用于置信度数字等场景 |

### 字体层级

| 层级 | 大小 | 字重 | 行高 | 用途 |
|---|---|---|---|---|
| Display | 28px | 600 | 1.3 | 页面主标题（如评估结果分数） |
| H1 | 22px | 600 | 1.4 | 页面标题 |
| H2 | 18px | 600 | 1.4 | 区块标题、卡片标题 |
| H3 | 16px | 500 | 1.5 | 子标题、强调文字 |
| Body | 15px | 400 | 1.6 | 正文、AI 回复、说明文字 |
| Caption | 13px | 400 | 1.5 | 辅助说明、来源注释 |
| Micro | 11px | 400 | 1.4 | 极小注释、置信度、版权 |

## 五、组件规格

### 按钮

| 类型 | 背景 | 文字色 | 高度 | 字号 |
|---|---|---|---|---|
| Primary | `#4A7B7B` | `#FFFFFF` | 52px | 16px / 600 |
| Secondary | `transparent` + border `#4A7B7B` | `#4A7B7B` | 52px | 16px / 500 |
| Ghost | `transparent` | `#6B6B6B` | 44px | 14px / 400 |
| Danger | `#9B4040` | `#FFFFFF` | 52px | 16px / 600 |
| Disabled | `#E8E4DE` | `#ABABAB` | 52px | 16px / 400 |

### 输入框

- 背景：`#FAFAF8`
- 边框：`1px solid #E8E4DE`
- Focus 边框：`1.5px solid #4A7B7B`
- 圆角：12px
- Padding：14px 16px
- 字号：15px

### 卡片

- 背景：`#FAFAF8`
- 边框：`1px solid #E8E4DE`
- 圆角：16px
- 阴影：`0 2px 12px rgba(0,0,0,0.06)`
- 内 padding：16px

### 状态徽章（红黄绿）

- 圆角：999px
- Padding：4px 10px
- 字号：13px / 500
- 配色参考上方状态色表

### Toast 提示

- 位置：右下角，距底部 24px
- 背景：`#1C1C1E`（暗色）
- 文字：`#FAFAF8`
- 圆角：10px
- Padding：12px 16px
- 字号：14px
- 自动消失：2 秒

## 六、MVP 页面视觉焦点说明

### P0 · 首页
**视觉焦点**：情绪状态选择卡片组（3-4 张）
- 卡片大，图标+短文案，用户第一眼就能点
- 顶部一行产品名+极短 tagline，不抢焦点
- 底部小字：隐私承诺
- **默认展示状态**：正常态，4 个情绪入口可点击

### P1 · 问卷页
**视觉焦点**：当前题目的选项区
- 题目编号（第 X/7 题）置顶，占比小
- 题目文字 H2 大小，加粗
- 选项卡片大，全宽，选中态有明显高亮（左边框+背景变色）
- 底部固定：上一步（ghost）+ 下一题（primary，未选时 disabled）
- **默认展示状态**：Q3（中间题目，展示已选一项的高亮态）

### P2 · 评估结果页
**视觉焦点**：状态等级 + 分数区块
- 最顶部大号显示等级（绿/黄/红）+ 对应颜色背景块
- 分数用 Display 字号（28px）突出
- AI 解释文字在分数下方，正常 Body 大小
- 底部：主 CTA 按钮（全宽）+ 次 CTA（ghost，小）
- **默认展示状态**：黄色（Caution）等级，置信度正常

### P3 · 情绪聊天页
**视觉焦点**：对话气泡区
- 用户气泡右对齐，AI 气泡左对齐
- AI 气泡左上角带情绪标签徽章
- 输入框固定底部，发送按钮内嵌
- 微干预卡片从底部弹出，带关闭按钮
- **默认展示状态**：3-4 条对话已有，展示情绪标签和一张微干预卡

### P4 · 消息改写页
**视觉焦点**：改写结果卡片区
- 原文输入区在上方（占 30% 高度）
- 改写卡片竖向排列，第一张（温和版）完整可见
- 每张卡片：版本标签 + 内容 + 风险徽章 + 复制按钮
- 第 2、3 张卡片毛玻璃遮罩（免费用户）
- **默认展示状态**：已生成结果，展示 3 张卡片（1 可用 + 2 遮罩）

### P8 · 安全拦截页
**视觉焦点**：资源列表（热线卡片）
- 不用红色背景，保持温和
- 顶部关怀图标 + 标题（"我注意到你现在可能很难受"）
- 资源卡片列表，每条可点击拨打
- 底部唯一按钮："我明白了"
- **默认展示状态**：自残/自杀触发态

## 七、给 AI 工具的原型生成指令模板

每次生成单页原型时，用以下结构作为 prompt 前缀：

```
设计一个移动端页面，宽度 390px（iPhone 14 标准宽度）。

设计规范：
- 背景色：#F5F3F0
- 主强调色：#4A7B7B
- 字体：PingFang SC（中文）+ DM Sans（数字/英文）
- 卡片圆角：16px，阴影：0 2px 12px rgba(0,0,0,0.06)
- 按钮高度：52px，圆角：12px
- 页面左右 padding：20px
- 风格：calm, trustworthy, emotionally steady
- 禁止：粉色系、渐变霓虹、医疗冷白

当前页面：[页面名称]
视觉焦点：[对应焦点说明]
展示状态：[默认展示状态]

页面内容要求：
[从 prd.md 第十三节对应页面的组件列表粘贴]
```

## 八、Figma 组件命名规范

按以下命名规则在 Figma 中建立 Component：

```
[模块]/[组件名]/[变体]

示例：
Assessment/StatusBadge/Green
Assessment/StatusBadge/Yellow
Assessment/StatusBadge/Red
Chat/MessageBubble/User
Chat/MessageBubble/AI
Chat/MicroInterventionCard/Default
Rewrite/VariantCard/Unlocked
Rewrite/VariantCard/Locked
Global/Button/Primary
Global/Button/Secondary
Global/Button/Disabled
Global/PaywallBanner/Default
Global/SafetyInterstitial/Default
```
